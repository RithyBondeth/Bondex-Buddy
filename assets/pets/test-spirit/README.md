# Temporary Phase 1 sprite

`reference.png` is a copy of the generated moon-cat concept in `docs/design/concepts/`. It is used only to exercise Canvas rendering and alpha hit testing; it does not select the final pet.

The renderer crops transparent padding, samples the concept into a maximum 48 × 48 pixel area without smoothing, and displays the entire 110 × 100 Canvas at 2×. This is a test rendering pipeline, not an approved palette-clean sprite sheet.

Source: built-in Imagegen concept exploration, 2026-11-17. Replace with an approved native-grid sprite before final animation work.
